# MoonBit プロジェクトのコマンド

## 基本的なビルドコマンド
- `moon build` - 現在のパッケージをビルド
- `moon check` - パッケージのチェック（オブジェクトファイルを生成しない）
- `moon run` - メインパッケージを実行
- `moon test` - 現在のパッケージのテストを実行
- `moon clean` - targetディレクトリを削除

## コード品質とフォーマット
- `moon fmt` - ソースコードをフォーマット
- `moon info` - すべてのパッケージの公開インターフェース（.mbti）ファイルを生成

## ドキュメンテーション
- `moon doc` - ドキュメントを生成

## 依存関係管理
- `moon add` - 依存関係を追加
- `moon remove` - 依存関係を削除
- `moon install` - 依存関係をインストール
- `moon tree` - 依存関係ツリーを表示

## 新規作成
- `moon new` - 新しいMoonBitモジュールを作成

## ベンチマーク
- `moon bench` - 現在のパッケージのベンチマークを実行

## タスク完了時に実行すべきコマンド
1. `moon check` - コードの構文とタイプチェック
2. `moon fmt` - コードのフォーマット
3. `moon test` - テストの実行
4. `moon build` - ビルドの確認
