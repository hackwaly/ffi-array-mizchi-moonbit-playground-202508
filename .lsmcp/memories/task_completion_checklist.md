# タスク完了時のチェックリスト

コード変更を行った後は、以下のコマンドを順番に実行して品質を確保してください：

## 1. 構文とタイプチェック
```bash
moon check
```
コードの構文エラーや型エラーがないことを確認

## 2. コードフォーマット
```bash
moon fmt
```
MoonBit標準のコードフォーマットを適用

## 3. テスト実行
```bash
moon test
```
すべてのテストが通ることを確認

## 4. ビルド確認
```bash
moon build
```
プロジェクトが正常にビルドできることを確認

## 5. 実行確認（メインパッケージがある場合）
```bash
moon run
```
プログラムが正常に動作することを確認

## 注意事項
- コミット前には必ず上記のチェックを実行
- テストファイル（*_test.mbt）を変更した場合は特にテストの実行を忘れずに
- 新しい依存関係を追加した場合は `moon install` を実行
